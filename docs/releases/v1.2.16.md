# v1.2.16

- 改善安卓手机系统 Miracast 镜像的音视频卡顿：短时 RTP 乱序重排、按 TS 流区分音视频丢包、视频损坏后主动请求关键帧恢复。
- 解码器短时繁忙时重试同一视频访问单元和 AAC 帧，避免直接丢弃；音频按 PTS 判断真实积压，避免按队列条数频繁截断声音。
- 设置移至右上角齿轮下拉菜单，可直接切换开关和语言；支持遥控器菜单键和设置键。
- 合并 website 分支的 DLNA 发现、事件订阅和播放会话兼容改进，以及 AirPlay URL/HLS 播放状态改进；保留主分支 UxPlay、字幕和竖屏修复。
- 不包含手动网卡选择，也不引入额外 120ms 的视频定时送显缓冲。

安装包提供 ARM32、ARM64 和 universal，版本码 25，应用 ID 沿用正式版 `top.jast.miracastreceiver`，可覆盖同签名的 v1.2.14/v1.2.15。使用 `com.weekd.miracastreceiver` 调试包的设备需先退出旧应用，避免端口冲突；两个包名之间不共享设置。

Miracast 修复在 116 ARM32 接收设备上通过安卓手机系统投屏验证，用户确认流畅；该实测发生在主分支合并前。合并后的发布构建另行完成单元测试、签名和架构检查，ARM64 本次未重新实机回归。

UxPlay 原生库沿用 v1.2.15，附件继续提供其对应源码与构建说明。应用源码见本版本 tag。

本机 Android lint 受 SDK 元数据 `37.0` 解析错误影响未能运行；发布构建跳过相关 lint 任务，不将其标记为通过。
