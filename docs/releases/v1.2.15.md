# v1.2.15

## 更新内容

- 修复小米相册 DLNA 投屏连接无反应、取消后再次连接仍显示投屏状态的问题：兼容 SOAPAction 请求头的大小写，修正 ConnectionManager 和 RenderingControl 的 SOAP 响应命名空间。
- 修复 iOS 相册竖屏视频旋转后内容变得很小的问题：识别 AirPlay 编码画面两侧黑边，按实际内容缩放。
- 修复旋转后画面放大却仍然模糊的问题：UxPlay 现在使用接收端设置的分辨率，并接收旋转后的更新。重新连接后，iPhone 可协商竖向画布，避免将横向码流中的低分辨率竖屏内容直接放大。

## 安装与验证

- Android 6（API 23）及以上；提供 ARM32、ARM64、universal 安装包，可覆盖安装 v1.2.14 并保留设置。
- MIX 2S ARM64 接收端已验证小米相册照片显示、iOS 视频旋转放大，以及重连后实际接收 1080×2160 H.264 码流；用户确认清晰度明显提升。
- 旋转后的分辨率声明需要在 iPhone 停止投屏并重新连接后生效，播放中缩放不会增加实际码流清晰度。
- ARM32 和 universal 包完成构建及签名、架构检查；本次未重新进行 ARM32 设备实测。
- 原生库沿用 v1.2.14，附件继续提供其对应源码和构建说明。应用源码可从本版本 tag 下载。
- Android lint 仍受本机 SDK 37.0 元数据解析错误影响，未将其标为通过。

感谢 [UxPlay](https://github.com/FDH2/UxPlay) 与 [android-airplay-server](https://github.com/jqssun/android-airplay-server)。
